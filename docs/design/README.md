## 五条贯穿全文的原则

1. **算错就前功尽弃的地方用整数**
   所有价格、数量、金额走 `bigint` 定标 1e8，不碰浮点。舍入规则统一收在一个模块里。

2. **引擎必须是纯函数**
   不依赖数据库、不依赖网络、不调 `Date.now()`。换来的是任何一笔交易都能录成事件序列在测试里逐字重放。

3. **宁可说做不到，不要编数字**
   市价单吃穿 20 档就拒单，行情断线就暂停撮合，不伪造成交。

4. **账目自洽要可自动检查**
   钱包余额恒等于资金流水之和。引擎层每次 `apply()` 后断言，数据库层每小时对账。

5. **失真点写在纸上**
   `02-architecture.md` 第九节列了 10 条。每一条都对应一个"本可以造假但选择不造"的决定；后续改动如果会让某条变得更不诚实，就不该做。
