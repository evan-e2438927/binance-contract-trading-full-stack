## 一、这一讲做了什么

`/leaderboard` 从占位块变成真页面，左边榜单、右边三块：

| 区域 | 内容 |
| --- | --- |
| 周期切换 | 日榜 · 周榜 · 总榜，右边写「数据截至 2026-09-21（每日 UTC 00:00 快照）」 |
| 收益率榜 | 排名（前三名有奖牌色）· 昵称 · 收益率 · 权益 · 胜率 · 成交笔数；我自己那一行高亮并标「我」 |
| 我的排名 | 没登录提示登录；上了榜显示名次 + 收益率 + 三项明细 |
| 我的权益曲线 | 近 7 / 30 / 90 天，每日快照 + 最右端此刻的实时权益 |
| 榜单怎么算 | 收益率口径、快照时间、重置的影响、胜率口径 |

周期和天数都写进网址（`/leaderboard?period=daily&days=90`），刷新和分享保得住。

## 二、四个值得说的决定

### 1. 曲线缺的日子**断开**，不连过去

服务端每天 UTC 00:00 拍一次权益快照。某天没拍到（服务没起、机器关了），那天的权益**我们不知道**。

图上的处理是：**断开**。折线拆成好几段，中间留空。

连一条直线过去当然更好看，但那条线上的每一个点都是编的——这一页的读者会拿它判断自己的策略，不能给他一段实际上不存在的数据。这和「行情断线期间不补算成交」是同一条原则。

### 2. 横坐标按日期算，不按第几个点

如果按「第几个点」排，缺了三天的图和连着三天的图长得一模一样，缺口就藏起来了。按日期排，缺的那几天会占出一段真实宽度的空白——**缺口是看得见的**。

### 3. 没上榜时不猜原因

接口只告诉我们「你不在榜上」，没说为什么。可能是这一期没成交、可能是重置过账户、也可能是快照还没拍到。

所以页面把三种可能都列出来，不挑一个说。编一个「因为你这一期没有成交」出来，说错了比不说更糟。（要说准需要服务端加个字段，M11 的清单里本来就把它列成可选项。）

### 4. 榜单更新频率照实说

设计稿上写的是「每 30 分钟更新一次 · 基于账户权益净值排名」。这不对：榜单跟着**每日快照**走，一天更新一次。

按你 2026-09-19 定的，页面上写的是「数据截至 {日期}（每日 UTC 00:00 快照）」。

## 三、图是怎么画的

照 `dataviz` 的规矩来，这些不是审美偏好，是可检查的规格：

- 线 2px、圆角；面积填充只有 10% 的一层淡色，不是实心块
- 网格线是一格灰的细实线，压在数据底下不抢戏
- **只在最右端标一个数**，其余的值靠纵轴刻度和悬停读数——每个点都写数字等于没写
- **文字不用线的颜色**：黄色当正文在深色底上不好读，身份靠旁边那个色点表示
- 悬停时十字线**自动吸到最近的那一天**，读者瞄日期就行，不用对准那条 2px 的线
- 悬停读数是增强、不是唯一通道：同一份数据还有一张给读屏软件看的表，不用鼠标也读得到

颜色用的是全站那个品牌黄。跑过配色校验：**在深色底上的对比度达标**（单条线不涉及「多条线能不能分清」那几项）。

另外，这张图全程用整数运算（项目硬约束：钱不许用浮点）。只有最后一步「这个值在最低和最高之间的什么位置」才转成小数——那是画在第几像素，不是钱。

## 五、要你验收的（需要登录）

榜单部分不用登录就能看，你直接打开 `/leaderboard` 就行。**要登录才能验的是右边两块**：

1. 登录后「我的排名」显示的名次、收益率，和榜单里高亮那一行对不对得上
2. 权益曲线有没有画出来；切 7 / 30 / 90 天有没有反应
3. 曲线上的点和历史记录里的数对不对得上（鼠标悬停能读到每天的权益）
4. 如果中间有天没拍到快照，那里应该是**断开的**，不是一条斜线连过去
