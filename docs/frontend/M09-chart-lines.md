# M09 图上交易线 · 讲义

> 给不看代码的人。日期：2026-09-24 ｜ 对应模块：M09（交易页 K 线图）

## 一、这一讲做了什么

K 线图上画出和你自己有关的价位，不用在表格和图之间来回看：

| 线 | 长什么样 |
| --- | --- |
| 开仓均价 | 实线，多头绿、空头红，标签 `多 1.000 @ 84,200.0 · +123.46`（带未实现盈亏，跟着标记价实时变） |
| 强平价 | 黄色虚线，标签 `强平 83,400.0` |
| 限价挂单 | 实线，买绿卖红，标签 `限价卖出 0.500 @ 84,900.0` |
| 条件单（止盈止损） | 虚线，画在触发价上 |
| 跟踪委托 | 虚线，画在按最近一次跟踪价算出来的触发线上，标签里写明「会移动」 |

切币对时旧线自动清掉；仓位、挂单一变，线跟着增删改。

## 二、一件必须先说的事：**线上做不了按钮**

设计文档（`08` 第 4 节）写的是「开仓均价线可以在线上直接平仓」「挂单线可以点叉撤单」。
**这个做不到**，原因不在代码，在授权包：

那两个功能要用图表库的 `createPositionLine()` / `createOrderLine()`。我在浏览器里实际调了一下，
它直接抛出来：

```
Error: createPositionLine is only available on Trading Platform
```

我又去授权包的代码里搜了一遍，被这样挡住的一共三个接口：

```
createOrderLine       is only available on Trading Platform
createPositionLine    is only available on Trading Platform
createExecutionShape  is only available on Trading Platform
```

也就是说：**我们拿到的是 Charting Library 版，带按钮的交易线属于 Trading Platform 版**，
是两个不同的授权档次，不是配置能打开的。

所以这一版退回到库自带的**水平线**（`createShape`）：价位、颜色、标签、实线虚线都照画，
**但线上没有按钮**。平仓和撤单在下面的表格里点，那边本来就有。

> 要是以后公司拿到 Trading Platform 授权，换回 `createOrderLine` / `createPositionLine` 是一件小事——
> 「画什么」已经是独立的一份纯函数，只要换掉「怎么画」那一层。

同样的原因，「拖动挂单线改价」也没做。它本来就是 M09 的可选项，而且服务端没有改单接口，
拖动只能做成「撤了再下」，中间有一小段时间没有挂单——这个取舍等真需要时再单独讨论。

## 三、两个值得说的做法

### 1. 「画什么」和「怎么画」分开

难写的不是画线，是**对账**：哪条线该新建、哪条只是价格变了、哪条该删掉。

所以「当前仓位 + 当前挂单 → 该画哪些线」是一份**纯函数**（不碰图表库），能单独测，
现在有 14 条测试盯着它：空仓位不画、别的币对不画、强平价算不出来时不画、
未实现盈亏算不出来时标签里干脆不提（不写 0）、跟踪委托没收到过行情时不画……

### 2. 改价不重建

未实现盈亏跟着标记价走，**线上的文字每秒都在变**。如果每次都删了重画，线会一直闪。

所以同一条线有一个稳定的 key，价格变了只改坐标、文字变了只改文字。
实测验证过：把一条线的价格从 84,200 改成 84,250 之后，图表里那条线的**内部 id 没变**——
是改的，不是重建的。

另外两个坑也处理了：建线是异步的，等它建好时这条线可能已经不该存在了（单子撤了、切了币对），
这种情况建好立刻删掉；系统画的线锁住、选不中、不进图表保存的数据，用户不会误拖误删。

## 五、要你验收的（需要登录 + 有仓位）

图表画面我这边拍不到，**得你自己看一眼**：

1. 登录，开一个仓位，进交易页看 K 线图：应该有一条实线（开仓均价，多绿空红）和一条黄色虚线（强平价）
2. 线上的标签对不对得上下面表格里的数；未实现盈亏那一截应该跟着价格在动
3. 挂一张限价单：图上应该多一条线；撤掉它：线应该消失
4. 切到别的币对再切回来：不该残留上一个币对的线
5. 确认一下线**不会被你误拖动**（它们是锁住的）

如果你觉得「线上就是要有按钮」，那就是上面第二节说的授权版本问题，需要公司升级到 Trading Platform 版——
告诉我，我把这件事单独记成一条待办。
