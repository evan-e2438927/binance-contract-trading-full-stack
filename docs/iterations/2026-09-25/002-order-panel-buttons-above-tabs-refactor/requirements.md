## 原始需求

> 我想帮我圈出来的三个按钮放到 tab 上面去，它应该是 trade 页面中的下单面板。 你看一下。

附图为交易页下单面板（`apps/web/src/app/trade/_ui-components/order-panel/order-panel.tsx`）当前状态：顶部是「限价 / 市价 / 条件委托」三个 tab，下方黄框圈出「20x（杠杆）/ 全仓（保证金模式）/ 单向持仓（持仓模式）」三个按钮。

## 需求摘要

把下单面板里「杠杆 / 保证金模式 / 持仓模式」三个快捷设置按钮，从订单类型 tab（限价/市价/条件委托）下方，调整到 tab 上方。

## 需求详情

### R-001
- **描述**: 下单面板中，「杠杆 / 保证金模式 / 持仓模式」按钮行显示在「限价 / 市价 / 条件委托」tab 行**上方**（当前是下方），两者互换垂直顺序；面板内其余区块（双向持仓下的开仓/平仓行、可用余额、价格/数量输入、预估信息、买卖按钮、账户信息）相对顺序与内容不变
- **置信度**: 高（0.9）— 用户截图明确圈出了要移动的元素，目标位置（tab 上方）表述无歧义；组件已定位到唯一实现（`order-panel.tsx`），无同名竞品组件
- **标注**: [✅ 已确认]

## 验收标准

### AC-001: 按钮行显示在 tab 上方（Happy Path）
- **关联需求**: R-001
- **场景维度**: happy-path
- **Given**: 用户打开交易页（`/trade/<symbol>`），下单面板正常渲染
- **When**: 面板渲染完成
- **Then**: 「调整杠杆 / 保证金模式 / 持仓模式」三个按钮组成的一行，出现在「限价 / 市价 / 条件委托」tab 行的**上方**；tab 行紧随其后，出现在按钮行**下方**；两行之间保留可见的垂直间距（不贴在一起）
- **验证方式**: playwright-mcp

### AC-002: 数据占位与禁用态在调整顺序后保持不变（Error）
- **关联需求**: R-001
- **场景维度**: error
- **Given**: `config`（`symbolConfigQuery`）尚未返回或用户未登录，导致 `leverageNum` 为 `null` / `config` 为 `undefined`
- **When**: 面板在新顺序下渲染
- **Then**: 杠杆按钮显示占位符 `PLACEHOLDER`（现有 `--` 逻辑不变，不因调整顺序而改写数据回退逻辑）；未登录（`loggedIn === false`）时三个按钮仍为 `disabled` 状态，点击不打开对应弹窗
- **验证方式**: playwright-mcp

### AC-003: 双向持仓开/平仓行位置不受影响（Boundary）
- **关联需求**: R-001
- **场景维度**: boundary
- **Given**: 账户持仓模式为双向持仓（`positionMode === "HEDGE"`），面板会额外渲染「开仓/平仓」切换行
- **When**: 按钮行与 tab 行互换顺序后再渲染
- **Then**: 「开仓/平仓」行仍然渲染在 tab 行**下方**、价格/数量输入区域**上方**（即整体顺序变为：按钮行 → tab 行 → 开仓/平仓行 → 其余表单），不会被插入到按钮行与 tab 行之间
- **验证方式**: playwright-mcp

### AC-004: 点击行为与弹窗不变（UI State）
- **关联需求**: R-001
- **场景维度**: ui-state
- **Given**: 已登录用户看到调整顺序后的按钮行
- **When**: 依次点击「调整杠杆」「保证金模式」「持仓模式」三个按钮
- **Then**: 分别打开 `LeverageDialog` / `MarginModeDialog` / `PositionModeDialog`，行为与调整前完全一致（本次不改动按钮点击逻辑、状态管理，只改 DOM 顺序与间距）
- **验证方式**: playwright-mcp

## 需求边界

### 包含 (In Scope)
- 交换 `order-panel.tsx` 中「订单类型 tab 行」与「杠杆/保证金模式/持仓模式按钮行」两个 JSX 区块的垂直顺序
- 相应调整两行的上边距（`pt-3.5` 等 Tailwind 类）以保持视觉间距一致

### 不包含 (Out of Scope)
- 不改变按钮/tab 的点击逻辑、状态管理（`useOrderFormStore`、`dialog` state 等）
- 不改变按钮/tab 的样式主题（颜色、圆角、字号）
- 不改变双向持仓「开仓/平仓」行、价格数量输入区、预估信息区、买卖按钮、账户信息区的内容或逻辑
- 不涉及 `apps/server`、`packages/engine`、`packages/db` 任何改动
- 不涉及跟踪委托表单（T-13，位于仓位 TP/SL 弹窗，是完全独立的另一个 tab 组件，与本次改动的下单面板 tab 无关）
