## 一、跟踪委托是什么

普通止损单的触发价是**钉死的**：你设 48,000，价格涨到 60,000 它还在 48,000 等着，前面赚的那一截保不住。

跟踪委托的止损线**跟着价格走**：

```
你做多，挂一张回调率 1% 的跟踪委托

价格 50,000 → 线在 49,500
价格 52,000 → 线跟上来，49,500 变 51,480     ← 只往上挪
价格 51,000 → 线不动，还在 51,480           ← 不会退回去
价格 51,480 → 触发，按市价平仓
```

一句话：**价格每创一次新高，止损线就往上抬一次；从最高处回撤够 1% 就平掉。**做空反过来。

## 二、两个参数

| 参数 | 是什么 | 不填会怎样 |
| --- | --- | --- |
| **回调率** `callbackRate` | 你能容忍从最有利处回撤多少，百分数。币安接口允许 **0.1% ~ 10%** | 必填，不填拒单 |
| **激活价** `activationPrice` | 价格先要碰到它，这张单才开始算回撤 | 不填 = **从下单那一刻开始跟** |

激活价的用处：现在 50,000，你想"先涨到 52,000 再开始保护"，就把激活价设 52,000。在那之前价格怎么跌都不触发（但最高价一直在记）。

币安有个方向限制（错误码 -2021）：**卖单的激活价必须高于现价，买单必须低于现价**。填反了说明意思是"我现在就要触发"，那应该直接下市价单。

## 三、这一讲最该记住的一件事

**币安的官方接口文档，这一段是坏的。**

触发条件那两行长这样（我从币安页面背后的数据里原样取出来的）：

```
BUY: the lowest price after order placed = the lowest price * (1 + callbackRate)
SELL: the highest price after order placed >= activatePrice, and the latest price
```

两行都断了。原因是他们的文档渲染把 `<=` 当成 HTML 标签给吃掉了——不是显示 bug，是**页面背后的数据里就已经没有了**。

按 CLAUDE.md 的规矩（不许凭记忆写币安的规则），我换了一条路：币安自己的帮助中心有一篇《What Is a Trailing Stop Order?》，里面用表格写着「激活价 ≤ 最高价」「回调幅度 ≥ 回调率」。两边剩下的部分互相吻合，缺的那半句用它补齐。

**这是全项目唯一一处靠两个来源拼出来的规则**，已经在 `07-binance-reference.md` 第 14 节写清楚了出处和这件事本身，等币安把文档修好了要回来核对。

还有一处两边不一致：回调率范围，**接口**写 0.1% ~ 10%，**帮助中心**写 0.01% ~ 20%。我们按接口的来——我们对外也是 API。

## 四、实现上的几个选择

### 1. 追踪价每跳一次都在变，但不推给前端

`trackedPrice`（现在跟到哪了）是这张单最有信息量的一个数，但它**每来一笔行情就可能变**。要是每次变都推一条订单更新，一秒几十条，前端根本看不过来，WS 通道也会被这种噪音占满。

所以：**内存里照常更新，但不发事件**（缺口 #53）。前端要看当前跟到哪，走 REST 拉挂单列表，列表里的值可能略旧——委托表那一列写的是「回调 1% · 跟到 52,000」，旧一点不影响判断。

这和第 06 讲"排队位置变化不发事件"是同一个取舍。

### 2. 顺序：先更新，再判断

一笔行情进来，要先把追踪价更新到新高，**再**判断要不要触发。反过来的话，价格一路上涨反而会拿旧的最高价去算回撤，把单子提前打掉。

测试里专门有一条盯着这个：价格从 50,000 一路涨到 52,000，中途一次都不能触发。

### 3. 舍入往对用户有利的方向偏

回撤的那一段距离用"向上取整"算，意味着**止损线离得稍微远一点点**。哪怕只差一个最小价格单位，也不该因为舍入把用户的单子提前打掉。

### 4. 和已有的条件单合并成一类

止盈止损单和跟踪委托，在引擎眼里是同一种东西——挂着等条件、未触发时不冻结保证金、共用"所有币对合计 200 张"的上限。所以校验链里它们统一成一组，不是各写一套。

### 5. 不支持"触发时平掉全部仓位"

币安的 `closePosition` 只配止损市价 / 止盈市价，**不配跟踪委托**。所以下跟踪委托必须写死数量。前端那个表单默认帮你填满当前仓位。

## 七、要你验收的（需要登录，而且要有仓位）

1. 开一个仓位 → 点仓位行的止盈止损 → 切到第三个 tab「跟踪委托」
2. 填回调率（或点 0.5% / 1% / 2% / 5% 的快捷按钮），看下面「按现在算，触发线在 ⋯」是不是合理
3. 确认挂出，到「当前委托」里看这张单：类型显示「跟踪委托」，触发条件那一列显示「回调 1% · 跟到 xxx」，状态是「跟踪中」
4. 盯一会儿：价格往有利方向走之后，**刷新一下**，「跟到」的数应该跟上去了（它不会自己实时跳，见上面第四节第 1 条）
5. 真被触发时，应该按市价平仓，历史委托里能看到这张单 FILLED

另外可以试试填个方向反了的激活价（做多时填一个比现价低的），应该被拒，提示「卖出方向的激活价要高于当前价」。
